# 报告数字复核材料

`coursework_evidence.zip` 保存本次报告对应的运行输出，包括原始预测、概率或 logits、指标、数据划分清单、冻结协议、训练日志和模型统计。包内 `manifest.json` 记录每个文件的 SHA256。

在仓库根目录执行 `python scripts/verify_evidence.py`，程序直接读取压缩包。只依赖 Python 标准库和 NumPy，不解压到训练目录，不启动训练或模型推理。

复核范围包括92组评价的233,728条预测、八次60轮结构训练、四次15轮验证对照、四种结构双种子均值与样本标准差，以及12次外部图片预测和验证集校准阈值。分类指标均从逐图整数标签重新计算。

包内保存原始运行名和路径，便于对应报告表9.2。原始训练使用的脚本指纹随协议保留。当前命令行默认权重已调整为 DS，历史评价数据保持原始记录。
